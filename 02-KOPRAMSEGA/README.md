## 📖 Tentang Project

**KOPRAMSEGA** adalah sistem manajemen digital yang dibangun khusus untuk organisasi kepramukaan sekolah. Aplikasi ini menggantikan pencatatan manual dengan sistem terpusat berbasis Google Sheets & AppSheet — lengkap dengan sistem login, jadwal kegiatan, dan pengumuman real-time. Ditujukan untuk pengurus dan anggota Pramuka dalam mengelola kegiatan sehari-hari secara lebih rapi dan mudah diakses.

<br/>

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---|---|
| 🔐 **Login System** | Autentikasi pengguna berbasis role & password |
| 👤 **Manajemen User** | Data anggota lengkap: nama, kelas, email, role, status, foto |
| 📅 **Jadwal** | Kalender & jadwal kegiatan kepramukaan |
| ⏱️ **Timer** | Pengatur waktu untuk sesi latihan |
| 🥾 **Latihan** | Pencatatan riwayat & progres latihan pramuka |
| 📢 **Pengumuman** | Papan informasi & pengumuman organisasi |

## 🚀 Cara Menjalankan

1. Buka [Google Apps Script Editor](https://script.google.com/home/projects/1uvwGn_ACqSCuTNKX4G8mCG_Jtde4Ahh5YMPX6te_p0v6ZJyNB7m-0aVr/edit) project ini
2. Pastikan sudah terhubung dengan spreadsheet database (lihat badge Database di atas)
3. Klik **Deploy > New deployment > Web app**
4. Atur akses sesuai kebutuhan (misal: "Anyone")
5. Klik **Deploy**, salin URL yang dihasilkan — itu jadi link Live App
6. Buka URL tersebut di browser untuk mengakses aplikasi
