## 📋 Fitur

- **Tugas** — catat dan pantau daftar tugas harian
- **Pengeluaran** — catat pemasukan dan pengeluaran harian
- **Catatan Harian** — jurnal singkat aktivitas sehari-hari
- Manajemen user (login per pengguna)
